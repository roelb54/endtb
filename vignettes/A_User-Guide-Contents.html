A. User Guide Contents

This document is a user’s guide for the tbvax model and contains the following sections:

  • Introduction and background
    Definition of the tbvax model and its purpose
    Background on tbvax as a system of differential equations

  • Demography
    Details about data used for the population composition, births and deaths, and about adjusting the population composition over time

  • Model Specification in XML
    Details about specifying tbvax models in XML:

    • a simple SIR model

    • an SEIR model with two SES states

    • an SEIR model with two SES states and counting disease incidence

    • a TB model including HIV with documentation about

      • the format of incidence files

      • transition matrices for e.g. TB progression

      • treatment matrices to force (time dependent) state transitions

      • TB.infectivity

      • TB.transmission

      • contacts matrices

    • an HIV TB model with a TB vaccine

    • Using incidence files to impose a prevalence distribution for e.g. the RISK dimension

  • Output and evaluation of targets
    Details about the stocks, flows and hits output and about the specification of targets to be evaluated in a so-called targets file

  • Working principle of using matrix multiplication to calculate derivatives of state variables

  • Optimization [TO DO]

  • R version and libraries [TO DO]
